# 보호막 HP 표시

유닛 위 공통 체력바와 오른쪽 유닛 정보 패널에 회색 보호막 구간 추가. 체력 구간 오른쪽에 보호막을 붙이고, 수치에는 회색 `+보호막` 표시. 보호막이 없으면 기존 HP 표시 유지.

표시 기준량은 `max(최대 HP, 현재 HP + 보호막)`. 현재 체력과 보호막을 같은 기준량으로 나눠 막대 안에 표시. 최대 체력 상태나 매우 큰 보호막에서도 회색 구간이 보이며 바깥으로 넘치지 않음.

`HealthBarFill`은 HP·보호막 비율과 DOTween 표시 담당. `UnitHealthBar`와 `UnitInfoPanel`은 체력·효과 변경 이벤트를 구독하여 값 전달. 체력이 감소하지 않는 보호막 피해에도 즉시 수치 갱신. 만료·해제·회복·사망·풀 반환 시 구독과 애니메이션 정리.

체력 피해 계산과 보호막 흡수 규칙은 기존 전투 로직 사용. 추가 Canvas 없음. 회색 Image는 마우스 입력을 가리지 않음.

타이틀 부제와 스테이지 1-1 카드의 부제 제거. 프리팹 및 신규 생성 셋업에 반영.
