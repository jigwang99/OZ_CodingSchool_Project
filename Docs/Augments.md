# 선택형 강화

스키마 4의 Augments 표에서 공통 강화 8종 조회. 1-2·2-1·3-1은 Rounds.offers_augment로 지정.
아직 선택하지 않은 강화에서 중복 없는 후보 3개 추첨. 선택하지 않은 후보는 다음 선택에 다시 등장 가능.
강화 전용 난수는 상점 난수와 분리. 후보·선택 ID·완료 라운드는 AugmentState에 유지. 디스크 저장은 포함하지 않음.

## 입력 권한

| 상황 | 허용 |
|---|---|
| 강화 창 열림 | 강화 선택·Hide choices 버튼만 허용 |
| 강화 창 닫힘 | 유닛 선택·배치·교환과 Show choices 버튼 허용 |
| 강화 선택 완료 | 기존 준비 단계의 구매·판매·XP·새로고침·전투 시작 허용 |

창을 닫아도 후보·강화 선택 단계 유지. 다시 열 때 재추첨 없음.
닫힌 상태에서도 게임 시작·구매·판매·XP 구매·상점 새로고침은 UI와 진행 명령 양쪽에서 차단.
열린 상태의 전체 화면 Raycast와 드래그 비활성화로 배경 입력 차단. 닫기·열기 토글은 모달 본문과 분리해 항상 표시.
UI는 현재 HUD의 공유 Canvas·기본 TMP 폰트를 사용한 영문 프로토타입. 선택 UI·카드는 에디터에서 저장한 프리팹이며 DOTween으로 열림 표현.

## 효과와 수명

5001 최대 체력 +15%, 5002 공격력 +15%, 5003 공격 속도 +15%, 5004 스킬 위력 +20%.
5005 시작 보호막 최대 체력 10%·5초, 5006 선택 즉시 골드 +8, 5007 선택 이후 승리 정산 골드 +2, 5008 시작 마나 +20.
능력치·마나 보너스는 ModifierSourceKind.Augment 출처로 교체. 새 구매·합성 결과에도 재적용.
최대 체력 강화는 준비 중 반영 후 완전 회복. 다음 전투의 BeginBattle도 강화된 최대 체력을 사용.
시너지와 강화의 시작 마나는 출처별 합산 후 최대 100으로 제한. 시작 보호막은 시너지 시작 처리 후 별도 출처로 적용.
즉시 골드는 선택 확정에서 한 번, 승리 골드는 기존 중복 정산 방지 경계 안에서 지급. 패배에는 추가 골드 없음.
풀 반환·새 Configure에서 유닛 수정자·시작 마나 출처 초기화. 선택 기록은 RunState 소유이므로 새 도전 생성 시 초기화.

## 연결·데이터

시너지 패널은 64px 아래로 이동하고 위쪽에 SelectedAugments 요약 바 표시.
바를 호버하면 선택한 모든 증강의 이름·효과 표시. 0개이면 선택 시점 안내, 최대 3개이면 설명 높이 자동 조절.
설명은 Raycast를 받지 않아 전장 입력을 가리지 않음. 강화 선택 모달이 열리면 호버와 설명 즉시 차단.
공유 HUD Canvas·TMP·DOTween 사용. 새 도전 상태의 선택 목록으로 갱신하며 시너지 최대 높이는 하단 상점 위에 맞춰 조정.
PixelTactics > Setup > Connect Selected Augments UI로 프리팹 연결. 기존 씬의 BattleHUD 참조를 통해 반영.

PixelTactics > Setup > Connect Augment UI: 기존 BattleHUD에 중첩 프리팹 연결. 별도 씬 오브젝트 배치 불필요.
Docs/Sheets/Augments.csv와 Manifest.csv를 원격 시트에 반영한 뒤 Sheets Import 사용. 원격 시트는 이 구현에서 수정하지 않음.
이전 스키마 1~3은 강화 없이 실행 가능. 배포 전 로컬 Addressables 재빌드 필요.
PixelTactics > Checks > Run Augment Checks: 12라운드 선택·경제·난수 및 실제 모달·드래그·효과·풀 재사용 검사.
