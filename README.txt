PixelTactics - 간단 조작법

[게임 시작]
실행 파일(.exe)을 연 뒤 [시작하기] → [1-1] 선택 → [시작].
진행 중인 저장이 있으면 타이틀의 [이어하기]로 복원. 새 도전을 시작하면 기존 진행도 교체.

[기본 조작]
- 유닛 클릭: 유닛 선택 및 오른쪽 정보 패널 확인.
- 아군 유닛을 마우스 왼쪽 버튼으로 드래그: 청록색 전장 또는 아래 대기석에 배치.
- 다른 아군 유닛이 있는 칸에 놓으면 자리 교환. 배치할 수 없는 위치면 원래 자리로 복귀.
- 전장 배치 한도는 플레이어 레벨과 동일. 최소 1기를 배치한 뒤 [전투 시작] 클릭.
- 전투는 자동 진행. 전투 중에는 유닛 정보만 확인 가능하며 배치·구매·판매는 불가.

[상점과 성장]
- 하단 상점 카드 클릭: 골드로 유닛 구매. 구매한 유닛은 대기석에 배치.
- [새로고침]: 골드를 사용해 상점 갱신.
- [경험치]: 골드로 경험치 구매. 레벨이 오르면 전장 배치 한도 증가.
- 아군 유닛을 드래그하면 하단 상점이 판매 구역으로 전환. 그곳에 놓으면 표시된 골드를 받고 판매.
- 판매 구역 밖에서는 기존 배치·자리 교환을 사용. 드래그를 취소하면 상점 복원.
- 같은 종류의 1성 유닛을 세 번째 구매하면 자동으로 2성 합성.
- 유닛 위 ★는 1성, ★★는 2성. 대기석에서는 별만 표시. 파란 막대는 마나, 회색 막대는 보호막.
- 전장에 배치한 유닛의 종족·직업 시너지는 왼쪽 패널에서 확인.

[증강 선택]
- 증강 창이 나타나면 세 가지 카드 중 하나를 클릭해 강화 선택.
- [증강 닫기]로 잠시 닫고 유닛 배치 가능. [증강 열기]로 다시 열기.
- 증강 선택 전에는 창을 닫아도 구매·판매·새로고침·경험치 구매·전투 시작은 불가.
- 왼쪽 위 증강 영역에 마우스를 올리면 선택한 증강 확인.

[라운드 진행과 종료]
- 준비 단계의 구매·판매·합성·배치·증강 선택 후 자동 저장.
- 전투 중 종료하면 전투 직전 준비 상태부터 이어하기. 정산 완료 후에는 결과 화면부터 복원.
- 전투 결과의 [다음 라운드]를 눌러 계속 진행.
- 라운드 패배 시 목숨 1 감소. 목숨이 모두 소진되면 도전 종료.
- 마지막 라운드에서 승리하면 도전 성공.
- 최종 결과에서 [재도전] 또는 [타이틀 화면] 선택.
- 좌상단 [설정]에서 30·60·144 FPS 선택 및 [게임 종료] 가능. 최초 기본값은 60 FPS.
- 설정 패널 우상단 [X]로 닫기. 설정은 씬 전환 후에도 유지.
- 타이틀 화면의 [종료] 버튼으로도 게임 종료 가능.
