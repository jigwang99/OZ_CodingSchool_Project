PixelTactics - 간단 조작법

[게임 시작]
- 실행 파일(.exe)을 열고 [시작하기] → [1-1] 선택 → [시작].
- 진행 중인 저장이 있으면 타이틀의 [이어하기]로 복원.
- 새 도전이나 재도전을 시작하면 이전 도전의 진행도와 아이템 초기화.

[유닛 선택과 배치]
- 유닛 클릭: 오른쪽 정보 패널에서 능력치·스킬·장착 아이템 확인.
- 준비 단계에서 아군을 왼쪽 마우스 버튼으로 드래그해 청록색 전장 또는 아래 대기석에 배치.
- 다른 아군이 있는 칸에 놓으면 자리 교환. 배치할 수 없는 위치면 원래 자리로 복귀.
- 전장 배치 한도는 플레이어 레벨과 동일. 최소 1기를 배치한 뒤 [전투 시작] 클릭.
- 유닛 위 ★는 1성, ★★는 2성. 파란 막대는 마나, 회색 막대는 보호막.
- 배치한 유닛의 종족·직업 시너지는 왼쪽 패널에서 확인.

[상점·판매·합성]
- 하단 상점 카드 클릭: 골드로 유닛 구매. 구매한 유닛은 대기석에 배치.
- 유닛 구매는 준비 단계·전투 중·전투 종료 카운트다운 중에 가능.
- 아군을 드래그하면 하단 상점이 판매 구역으로 전환. 그곳에 놓으면 표시된 골드를 받고 판매.
- 전투 중에는 대기석 유닛만 판매 가능. 전장 유닛의 이동·판매와 대기석 유닛의 출전은 불가.
- 준비 단계와 전투 종료 카운트다운 중에는 전장·대기석 유닛 모두 판매 가능.
- 판매 구역 밖에 놓으면 준비 단계에서는 배치 시도, 전투·카운트다운 중에는 원래 위치로 복귀.
- [새로고침]: 골드로 상점 갱신. [경험치]: 골드로 경험치 구매. 둘 다 준비 단계에서만 가능.
- 같은 종류의 1성 유닛 3개는 자동으로 2성 합성.
- 전투 중에는 대기석 유닛끼리만 합성하며, 전장 유닛을 포함한 합성은 전투 종료 후 처리.

[아이템과 인벤토리]
- 전투 승리 보상으로 아이템 획득.
- 좌하단 [인벤토리] 클릭: 전장 왼쪽에 보관함 열기. 창 우상단 [X]로 닫기.
- 보관함을 열어도 전투 시간은 계속 진행.
- 아이템 클릭: 효과 확인. 아이템을 살아 있는 아군에게 드래그해 놓으면 장착.
- 장착 가능한 대상 유닛은 드래그 중 잠시 확대. 빈 공간이나 장비 3칸이 가득 찬 유닛에 놓으면 장착 취소.
- 유닛당 최대 3개 장착. 장비는 체력바 아래와 오른쪽 유닛 정보 패널에 표시.
- 장착은 준비 단계·전투 중에 가능. 해제는 준비 단계에서 유닛 정보 패널의 장비 아이콘 클릭.
- 유닛을 판매하면 장비는 인벤토리로 반환. 합성 시 장비를 이어받고 3칸을 넘는 장비는 인벤토리로 반환.
- 아이템은 현재 스테이지의 도전에서만 사용. 새 도전·재도전 시 초기화되며 이어하기에서는 유지.

[전투와 라운드 진행]
- 전투는 자동 진행. 한 진영의 생존 전투 유닛이 0명이 되면 종료하며 대기석 유닛은 이 판정에서 제외.
- 제한 시간 안에 적을 전멸시키지 못하면 패배.
- 일반 전투 종료 후 실제 시간 5초 동안 결과 표시, 이후 다음 전투의 준비 단계로 자동 전환.
- 카운트다운 중 구매·판매를 해도 남은 시간은 연장되지 않음.
- 다음 준비 단계에서 배치·구매 등을 마친 뒤 [전투 시작] 클릭.
- 패배 시 목숨 1 감소. 마지막 라운드에서 승리하면 도전 성공.
- 도전이 끝나면 최종 결과 화면 유지. [재도전] 또는 [타이틀 화면] 선택.

[증강 선택]
- 증강 창이 나타나면 세 가지 카드 중 하나를 클릭해 강화 선택.
- [증강 닫기]로 잠시 닫고 유닛 배치 가능. [증강 열기]로 다시 열기.
- 선택 전에는 창을 닫아도 구매·판매·새로고침·경험치 구매·전투 시작은 불가.
- 왼쪽 위 증강 영역에 마우스를 올리면 선택한 증강 확인.

[저장과 이어하기]
- 구매·판매·장착·해제·합성·배치·증강 선택과 전투 결과를 자동 저장.
- 전투 중 종료하면 해당 라운드의 준비 상태부터 이어하기. 전투 중 구매·판매·장착한 내용도 저장.
- 결과 카운트다운 중 종료하면 결과 화면부터 복원하고 다시 5초 뒤 다음 준비 단계로 전환.

[설정과 종료]
- 좌상단 [설정]에서 FPS 드롭다운(30·60·144) 선택, 효과음 음량 조절 및 [게임 종료] 가능.
- 최초 기본 FPS는 60. FPS와 효과음 음량은 재실행 후에도 유지.
- 설정 패널 우상단 [X]로 닫기. 설정 버튼은 타이틀과 전투 화면에서 모두 사용 가능.
- 타이틀 화면의 [종료] 버튼으로도 게임 종료 가능.
