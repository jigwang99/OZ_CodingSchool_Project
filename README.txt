PixelTactics - 플레이 안내

[실행]
압축을 모두 푼 뒤 게임 실행 파일(.exe)을 실행하세요.
실행 파일과 함께 제공된 폴더·파일은 같은 위치에 유지하세요.

[게임 시작]
1. 타이틀에서 [게임 시작]을 누르세요.
2. 좌우 화살표로 지역을 이동하고, 지도에서 스테이지를 선택하세요.
3. 오른쪽 패널의 [새로하기]로 시작하거나 [이어하기]로 저장한 도전을 불러오세요.
   이어하기는 선택한 스테이지의 저장 데이터가 있을 때 활성화됩니다.
4. 아군을 전장에 배치하고 [전투 시작]을 누르세요.

[기본 조작]
- 예상 수입: 상단 골드 아이콘·숫자에 마우스를 올리면 기본·이자·연승 항목 확인.
- 유닛 선택: 유닛을 클릭하면 오른쪽에 능력치·스킬·판매 가격·장비 표시.
- 유닛 배치: 준비 중 아군을 마우스 왼쪽 버튼으로 드래그해 전장 또는 대기석에 놓기.
- 자리 교환: 다른 아군이 있는 칸에 드롭.
- 유닛 구매: 하단 상점 카드 클릭.
- 유닛 판매: 유닛을 드래그하면 나타나는 하단 판매 구역에 드롭.
- 상점 새로고침: [새로고침] 버튼 또는 D키.
- 경험치 구매: [경험치] 버튼 또는 F키.
- 설정: 좌상단 [설정] 버튼. 패널 우상단 [X]로 닫기.

[배치·성급·시너지]
- 전장 배치 한도는 플레이어 레벨과 같으며, 최소 1기를 배치해야 전투 시작 가능.
- 배치할 수 없는 위치에 놓으면 원래 자리로 복귀.
- 같은 종류·성급 유닛 3개를 모으면 자동 합성. 최대 3성.
- 2성은 하늘색, 3성은 황금색 테두리로 구분.
- 전장에 배치한 서로 다른 종류의 유닛으로 종족·직업 시너지 적용.
- 왼쪽 시너지 목록에 마우스를 올리면 효과 확인.

[전투 중 가능한 조작]
- 전투는 자동으로 진행됩니다.
- 유닛 구매, 대기석 유닛 판매, 아이템 장착 가능.
- 전장 유닛의 이동·판매와 대기석 유닛의 출전은 준비 단계에서 가능.
- 전투 중에는 대기석 유닛끼리만 합성하며, 전장 유닛을 포함한 합성은 전투 종료 후 처리.
- 상점 새로고침과 경험치 구매는 준비 단계에서 가능.

[아이템]
- 승리 보상으로 획득. 좌하단 인벤토리 버튼으로 보관함 열기, 우상단 [X]로 닫기.
- 아이템에 마우스를 올리면 이름·능력치 확인. 유닛 정보창의 장착 아이템도 동일.
- 아이템을 살아 있는 아군에게 드래그해 장착. 합성 가능한 대상 위에서는 합성 결과 미리 표시.
- 유닛당 최대 3개 장착. 장착 가능한 대상은 드래그 중 잠시 확대.
- 정해진 재료 2개를 인벤토리에서 겹쳐 놓거나, 재료를 장착한 유닛에 다른 재료를 장착하면 상위 아이템으로 합성.
- 장비 해제: 준비 단계에서 유닛 정보창의 장비 아이콘 우클릭.
- 유닛 판매 시 장비는 인벤토리로 반환.
- 아이템은 해당 스테이지의 도전에서만 사용. 새로하기 시 초기화, 이어하기 시 유지.
- 인벤토리를 열어도 전투 시간은 계속 진행됩니다.

[증강]
- 증강 선택 창에서 세 가지 카드 중 하나를 선택하세요.
- 창을 잠시 닫으면 유닛 배치 가능. 다시 열기 버튼으로 선택 창 복귀.
- 증강을 선택하기 전에는 구매·판매·새로고침·경험치 구매·전투 시작 불가.
- 좌상단 증강 영역에 마우스를 올리면 선택한 증강 확인.

[전투 결과·스테이지 진행]
- 적을 전멸시키면 승리. 아군이 전멸하거나 제한 시간이 끝나면 패배.
- 일반 전투 결과는 5초간 표시한 뒤 다음 준비 단계로 전환.
- 골드·이자·승리 아이템 보상은 결과 카운트다운이 끝날 때 지급.
- 카운트다운 중에도 유닛 구매·판매 가능.
- 패배 시 목숨 1 감소. 목숨을 모두 잃으면 도전 종료.
- 마지막 전투에서 승리하면 스테이지 클리어 및 다음 스테이지 해금.
- 최종 결과 화면의 [스테이지 선택]으로 돌아가 다음 도전을 선택하세요.
- 잠긴 스테이지도 클릭해 정보 확인 가능. 지정 스테이지에 진입하면 해당 유닛 영구 해금.

[자동 저장·이어하기]
- 진행 상황은 자동 저장됩니다.
- 전투 도중 종료했다면 해당 전투의 준비 상태부터 이어집니다.
- 결과 카운트다운 중 종료했다면 결과 상태부터 복원됩니다.
- 새로하기 시 도전의 유닛·재화·아이템은 초기화되며, 클리어·유닛 해금 기록은 유지됩니다.
- Windows 저장 폴더:
  %USERPROFILE%\AppData\LocalLow\DefaultCompany\OZ_CodingSchool_Project\Saves

[설정·종료]
- 게임을 최소화하거나 다른 창으로 전환해도 전투·타이머·보상 처리는 계속 진행됩니다.
- FPS: 30 / 60 / 144 중 선택. 기본 60.
- 효과음과 배경음악 음량을 각각 조절. FPS·음량 설정은 재실행 후에도 유지.
- 지역별로 다른 배경음악 재생. 같은 지역의 전투 사이에는 음악 유지.
- 설정의 [스테이지 선택]으로 도전에서 나가거나 [게임 종료]로 종료 가능.
- 타이틀 화면의 [종료] 버튼으로도 종료 가능.
